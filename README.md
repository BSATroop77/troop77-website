# Troop 77

Static website for Scouts BSA Troop 77 (New Port Richey, Florida).

Plain HTML, CSS, and JavaScript with no build step. GitHub Pages serves this site from the root of the `main` branch.

The home page is the full-screen hero. About, calendar, news, adventures, photos, resources, and contact are separate pages. Asset and page links are relative so the site works under `/troop77-website/`.

https://bsatroop77.github.io/troop77-website/
